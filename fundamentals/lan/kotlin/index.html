Introduction

  • Multi-paradym programming language.
  • 2016 by jetbrains
  • Java Interoperability
  • Uses JVM [ compiles to bytecode ]
  • Coroutines
    1. Asynchronous
    2. Non-blocking
  • Doesn't need constructures as it has the data class
  • Compiler - kotlinc [ call it kotlin-c ] filename.kt -include-runtime -d <filename>.jar
  • -include-runtime — bundle the Kotlin standard library (kotlin-stdlib) into the produced JAR. Without this, the jar will need kotlin-stdlib on the classpath when running.
  • -d is destination
